# 1. Record architecture decisions

Date: 2026-11-19

## Status

Accepted

## Context

The plugin was built before any design records existed. Its spec and plan were
written afterwards from the code and the owner's design conversations.
Decisions with non-obvious reasons need a durable record for contributors.

## Decision

Record architecture decisions in `docs/adr/` as numbered Nygard-style ADRs.
ADRs 0002–0004 record decisions already made in v0.1–v0.3 (status Accepted).

## Consequences

New hard-to-reverse decisions get an ADR in the same change. Superseded ADRs
stay in place and link to their replacement.
